# Axius v6

Это будет рекриейт предыдущего ядра Axius [Тык](https://github.com/P-R-A-Y/Axius). Мне кажется код той версии выглядит перегруженным + содержит много ошибок и говнокода.
Это будет попытка пересмотреть то, что я создавал несколько лет под другим углом.

Я попытаюсь использовать методику 30 минут в день при написании этой версии.

# Где тут что лежит

Само ядро находится в директории `/lib/Axius` \
Шиммер лежит в директории `/src`

Я решил запихнуть ядро и мультитул в один проект, потому что так будет удобнее для работы в PlatformIO. После финализации тут будет только ядро, а код шиммера я вынесу в отдельную ветку его собственной страницы.
